Thiết kế màn Màn hình (`ProfileScreen`), và tuân theo format sau:
Ví dụ với A. Màn hình Trang chủ (`CustomerHomeScreen`)
0. Màn này thuộc tab nào, thuộc luồng tương tác nào để có thể xuất hiện màn này
1. Có các thành phần (components) nào ? (đặt tittle mỗi thành phần là A1, A2, ...)
2. components được thiết kế ra sao, sử dụng thư viện gì, text như nào, icon như nào (expo icon IonIcons)
3. components đó chỉ view, render data hay có thể click vào, nếu click vào được thì sẽ xử lý gì
4. components đó sử dụng API nào để lấy data hoặc call API nào để xử lý event

Ứng dụng vào để thiết kế rõ ràng cho #### A. Màn hình Trang chủ (`CustomerHomeScreen`)
