DANH SÁCH CHI TIẾT API BENGO DELIVERY SERVICE (FULL FIELD LIST)
================================================================================
CẤU TRÚC PHẢN HỒI CHUNG (Global Response Wrapper):
Mọi API đều được bọc bởi TransformInterceptor với cấu trúc sau:

{
  "statusCode": 200,
  "message": "Success",
  "data": { ... dữu liệu thực tế ... },
  "meta": {
    "timestamp": "2024-03-20T10:00:00.000Z",
    "apiVersion": "v1.2"
  }
}

Nếu có phân trang (Pagination), sẽ có thêm object "pagination":
{
  "statusCode": 200,
  "message": "...",
  "data": [ ... ],
  "pagination": {
    "total": 100,      // Tổng số bản ghi
    "count": 20,      // Số bản ghi trong trang hiện tại
    "per_page": 20,   // Số bản ghi mỗi trang
    "current_page": 1, 
    "total_pages": 5
  },
  "meta": { ... }
}

III. DRIVER (Tài xế) - DriverController
================================================================================

1. Cập nhật trạng thái hoạt động (PUT /driver/status)
   - Payload JSON:
     {
       "isOnline": true,
       "location": { "lat": 10.76, "lng": 106.66 }
     }
   - Response Data: { "success": true }

2. Lấy danh sách đơn chờ gần đây (GET /driver/orders/pending)
   - Params: ?lat=10.7&lng=106.6&radius=5
   - Response Data:
     [
       {
         "orderId": "60d0fe...",
         "distance": 1.5,
         "price": 50000
       }
     ]

3. Chấp nhận đơn hàng (POST /driver/orders/:id/accept)
   - Response Data:
     {
       "success": true,
       "order": {
         "id": "60d0fe...",
         "status": "ACCEPTED",
         "pickup": { "address": "...", "lat": 10.76, "lng": 106.66 },
         "dropoff": { "address": "...", "lat": 10.77, "lng": 106.67 },
         "totalPrice": 150000
       }
     }

4. Cập nhật trạng thái chuyến đi (PUT /driver/orders/:id/update)
   - Payload JSON:
     {
       "status": "PICKED_UP"|"DELIVERED",
       "proofImage": "http://..." // Tùy chọn (ảnh bằng chứng giao hàng)
     }
   - Response Data: { "success": true }

5. Cập nhật vị trí GPS thời gian thực (PUT /driver/location)
   - Payload JSON:
     {
       "lat": 10.76,
       "lng": 106.66,
       "heading": 90 // Tùy chọn (góc hướng đi)
     }
   - Response Data: { "success": true }

6. Tải lên tài liệu tài xế (POST /driver/documents)
   - Payload JSON:
     {
       "type": "LICENSE"|"VEHICLE",
       "imageUrl": "http://..."
     }
   - Response Data: { "success": true }

7. Xem thống kê thu nhập (GET /driver/stats)
   - Params: ?from=2024-03-01&to=2024-03-20
   - Response Data:
     {
       "totalEarnings": 500000,
       "totalTrips": 12,
       "rating": 4.9
     }

  8. Lấy lịch sử chuyến đi của tài xế (GET /driver/orders)
    - Params: ?page=1&limit=10&status=ALL|PENDING|ACCEPTED|PICKED_UP|DELIVERED|CANCELLED
    - Response Data:
      {
        "data": [
          {
            "id": "...",
            "status": "DELIVERED",
            "pickupAddress": "...",
            "dropoffAddress": "...",
            "totalPrice": 150000,
            "createdAt": "..."
          }
        ],
        "meta": {
          "total": 10,
          "page": 1,
          "limit": 10
        }
      }

VII. UPLOAD (Tải ảnh)
================================================================================

1. Upload hình ảnh (POST /upload)
   - Payload: FormData { file: binary }
   - Response Data:
     {
       "public_id": "BenGo-BE/abc123",
       "url": "https://res.cloudinary.com/.../abc123.jpg",
       "width": 800,
       "height": 600,
       "format": "jpg",
       "bytes": 102400
     }
================================================================================
GHI CHÚ:
- Các field có dạng "_id" là MongoDB ObjectId (String).
- Các field "createdAt", "updatedAt" là định dạng ISO Date String.
- "statusCode" trong JSON wrapper luôn trùng với HTTP Status Code.
